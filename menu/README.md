# Bitburnerスターターセット(仮)

## nuke.js (消費RAM：2.35GB)
効果：権限が奪取可能なサーバーを手当たり次第回収します。<br>
使用方法：`run nuke.js`

## scan.js (消費RAM：3.90GB)
効果(パターン1)：全階層のサーバーを走査し表示します。<br>
使用方法：`run scan.js`

効果(パターン2)：目的地サーバーへの移動パスを表示します。ターミナルにペーストしましょう。<br>
使用方法：`run scan.js <目的地サーバー名>`

## start.js (消費RAM：4.35GB)
効果：全サーバーにHackスクリプトとGrow&Weakenスクリプトをコピーし展開する。**※既存スクリプトは全てkillされます。**<br>
使用方法：`run start.js`
